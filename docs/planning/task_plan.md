## 关键决策

### 决策 1: 直接读取文件流
**选择**: 使用 `c.File(dbPath)` 直接发送文件
**原因**: 简单高效，避免复制操作，SQLite 支持多读
**替代方案**: 创建临时副本（增加复杂度和磁盘占用）

### 决策 2: 导出前警告
**选择**: 显示警告对话框，提醒用户文件包含敏感信息
**原因**: 平衡安全性和功能完整性，由用户负责保管
**替代方案**: 自动脱敏（可能破坏数据完整性）

### 决策 3: 独立按钮
**选择**: 添加独立的"导出数据库"按钮
**原因**: 清晰明确，不影响现有功能
**替代方案**: 下拉菜单或对话框选项（增加交互复杂度）
