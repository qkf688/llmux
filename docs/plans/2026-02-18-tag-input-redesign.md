# TagInput 组件重构设计

## 需求背景

在 `/setting` 页面中，"模型过滤规则"的"分隔符"和"后缀关键词"使用 `TagInput` 组件，通过按 Enter 键添加标签。在手机端，虚拟键盘的 Enter 键行为不一致，导致无法正常添加内容。

## 设计方案

### 交互布局

采用完全分离的布局方式：

```
┌─────────────────────────────────┐
│ [输入框 placeholder]   [添加按钮] │
└─────────────────────────────────┘
┌─────────────────────────────────┐
│  : free            [×]          │
│  -                 [×]          │
│                                 │  ← 空时显示提示文字
└─────────────────────────────────┘
```

### 交互细节

| 行为 | 效果 |
|------|------|
| 点击"添加"按钮 | 将输入框内容加入列表，自动清空输入框 |
| 按 Enter 键 | 同上（保留快捷键兼容性） |
| 输入重复内容添加 | 静默跳过，自动清空输入框 |
| 点击列表项右侧 × | 从列表移除该项 |
| 列表为空 | 显示灰色提示文字 |

### 组件接口

保持原有接口不变，调用方无需修改：

```typescript
export interface TagInputProps {
  value: string[]
  onChange: (tags: string[]) => void
  placeholder?: string
  className?: string
}
```

### 改动范围

**仅改动** `webui/src/components/ui/tag-input.tsx`
